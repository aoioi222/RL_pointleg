## 算法与信息边界

Actor 使用与 Rough 同顺序、同缩放的 45 维单帧本体观测。网络沿用 `512 → 256 → 128`、ELU、12 维高斯动作输出；Critic 保持原有 325 维特权观测。关节顺序、默认姿态和动作处理契约保持一致。

首轮 PPO 建议使用 50 Hz 控制、`gamma=0.995`、`lambda=0.95`、clip 0.2、学习率 3e-4、adaptive KL、目标 KL 0.01。其余先沿用 Rough 的网络与采样结构；这些是试验初值，不是已验证的最佳超参数。相较当前 Rough 的 `gamma=0.99`，0.995 为多秒越障保留更多延迟完成信号，仍需通过固定用例比较。

从经过评估的 Rough 模型初始化 Actor、Critic 权重，新任务重建优化器、课程与计数。相同任务断点续训才恢复完整训练状态。

训练奖励与规则可使用真实障碍坐标、接触和机器人几何，但这些信息不拼入 Actor。单帧本体观测没有绝对横向位置、航向和墙距：中线、航向代价可训练更少漂移的步态，不能赋予策略未观测位置的主动回中能力。当前方案依靠导航对准入口和经验证的扰动范围；如果以后要求途中主动导航修正，需要另行训练对应控制指令，不能仅增加中线惩罚权重。

## 总奖励：连续代价、路径塑形和事件分开

本方案的初始奖励定义为：

$$
r_t=-\Delta t\,C_t
+5\left[\gamma\Phi(x_{t+1})-\Phi(x_t)\right]
+0.5N_t^{\mathrm{首次子事件}}
+20I_t^{\mathrm{有效完成}}
-50I_t^{\mathrm{任务失败}}.
$$

其中：

- `C_t` 为每秒连续代价，包含阶段开关；原始归一化代价均非负。
- `Phi` 是沿合法路线的进度势函数，包含计算该路线所需的任务状态。
- 楼梯的首次子事件是六个规定落足面的首次有效覆盖，公式中的事件数按 `N_norm = N_raw × 3 / 6` 归一化；Jump 的首次子事件是有效起跳、完整越墙、合法落地，事件数不缩放。每回合子事件总额最多 1.5，不因楼梯阶数翻倍提高总额。
- 斜坡初版不另外发放路段正奖励，主要依靠路径塑形和最终完成事件。
- 完成和失败互斥，同一步出现失败条件时不给完成或新的正子事件。
- 所有数值都是在本文件定义的归一化和时间尺度下的首轮仿真初值。不能把这些权重直接乘现有未归一化函数，也不能解释为比赛分数或硬件额定值。

### 路径势函数

使用本回合从合法入口到出口的固定路线坐标 `s`，令 `L` 为相应路线长度：

$$
\Phi(x)=\operatorname{clip}\left(\frac{s(x)-s_{\mathrm{入口}}}{L},-1,1\right).
$$

推进和退回均改变该势函数，不使用历史最大进度，不把负进度截为零，也不同时叠加旧的单向正进度奖励。楼梯的台阶目标切换、Jump 的阶段切换均不重置路线坐标。

路线位于合法通道内；跳跃路线允许腾空跨墙，不沿墙体实体内部规划。越界与错误通过由独立失败逻辑处理，不因势函数增加而被抵消。

真正结束的吸收状态取 `Phi=0`，包括合法完成和任务失败，结算最后一次状态转移时统一处理。采样 rollout 截断或与任务结局无关的外部时间截断保持 bootstrap 语义，不擅自将其当作吸收状态。该边界会使结束帧包含势函数回收量，不能为了让日志更好看而删掉负项。

势函数只是学习信号，完整通过仍由真实几何、接触覆盖与恢复状态决定。

### MJLab 时间尺度适配

当前 `ManagerBasedRlEnvCfg.scale_rewards_by_dt=True`，管理器会执行 `函数输出 × weight × step_dt`。本方案固定采用以下一种适配方式：

| 奖励类型 | 函数返回值 | 配置权重 | 每控制步实际贡献 |
|---|---|---:|---|
| 连续代价 | 非负的 `g_phase × p` | `-lambda` | `-lambda × g_phase × p × dt` |
| 路径塑形 | `(gamma × Phi_next - Phi_now) / dt` | 5 | `5 × (gamma × Phi_next - Phi_now)` |
| 首次子事件 | `N_norm / dt` | 0.5 | 楼梯 `0.25 × N_raw`；Jump `0.5 × N_raw` |
| 完成事件 | `I_success / dt` | 20 | `20 × I_success` |
| 失败事件 | `I_failure / dt` | -50 | `-50 × I_failure` |

不再在管理器外追加相同事件，不对已经除过 dt 的现有奖励重复补偿。修改控制周期时，连续折扣按 `gamma_new = gamma_50Hz^(dt_new / 0.02)` 换算。

需要特别注意：当前 Rough 普通终止项的权重 -50，在 20 ms 下若函数只返回一次布尔 1，实际仅扣 1。本设计中的失败代价是一次真实扣 50，两者不是相同尺度。

## 连续代价的归一化和首轮权重

定义带容差的平方代价：

$$
D(z;\epsilon,\sigma)=\min\left(1,\left[\frac{\max(0,|z|-\epsilon)}{\sigma}\right]^2\right).
$$

单项上限是软代价的尺度控制；严重碰撞、关节越限及任务失败仍独立终止，不能因代价封顶而被允许。

以下表中数字为正的惩罚系数 `lambda`，写入 RewardTermCfg 时使用负号。

| 项目 | 归一化定义 | Elevation 初值 | Jump 初值与开关 |
|---|---|---:|---|
| 前向速度误差 `p_v` | `1-exp(-((vx_body-vx_cmd)/0.25)^2)` | 1.0 | 准备、起跳、腾空为 0；接管恢复为 0.25 |
| 中线偏差 `p_y` | `D(e_y;0.02 m,0.18 m)` | 1.0 | 全阶段 1.0 |
| 航向偏差 `p_heading` | 对 wrap 后的通道航向误差用 `D(误差;3°,12°)` | 0.5 | 全阶段 0.5 |
| 横向漂移 `p_lateral` | `D(v_cross;0.03 m/s,0.15 m/s)` | 0.5 | 全阶段 0.5 |
| 足端临边 `p_edge` | 支撑接触区域到合法边缘的余量不足代价 | 1.0 | 准备、落地和接管时 1.0；腾空为 0 |
| 支撑滑移 `p_slip` | 接触表面相对切向速度平方，以 0.15 m/s 归一化并封顶 | 0.5 | 有效支撑时 0.5；腾空为 0 |
| 参考姿态误差 `p_attitude` | 相对支撑面或阶段参考的滚转、俯仰软超差 | 0.5 | 全阶段 0.25，使用跳跃阶段的允许姿态范围 |
| 失控角速度 `p_omega` | 滚转、偏航角速度和较弱俯仰项的归一化平方 | 0.1 | 全阶段 0.1 |
| 支撑面离地范围 `p_clearance` | 相对支撑面正常离地范围的超差 | 初期 0；参考验证后 0.2 | 准备、起跳、腾空和首次触地为 0；恢复验证后至多 0.2 |
| 多余法向速度 `p_normal` | 仅平滑支撑段相对表面法向的多余运动 | 初期 0；验证后 0.1 | 初版 0 |
| 软关节限位 `p_joint` | XML 软限位外、硬限位内的超差，按关节范围归一化 | 0.2 | 全阶段 0.2 |
| 关节力矩 `p_torque` | `mean((tau/tau_sim_limit)^2)`，封顶为 1 | 0.02 | 全阶段 0.02 |
| 机械功率 `p_power` | `mean(abs(tau*qdot))/P_ref`，封顶为 1 | 初期 0；标定后 0.01 | 初期 0；标定后 0.01 |
| 动作变化率 `p_action` | `mean(((a-a_prev)/(dt*a_rate_ref))^2)`，封顶为 1 | 0.05 | 全阶段 0.02 |
| 非计划轻微连杆碰撞 `p_contact` | 归一化的有效碰撞强度，封顶为 1 | 0.2 | 0.2；严重撞击另行失败 |
| 超量落地载荷 `p_impact` | 超出对应阶段已标定软阈值的载荷 | 初期 0；标定后 0.5 | 初期 0；落地标定后 0.5 |
| 时间成本 | 常数 1 | 0.05 | 0.05 |

`vx_body` 和 `vx_cmd` 都使用 Rough 既有的机身坐标语义，不能把世界坐标速度直接减去机身速度命令。中线、航向和横向漂移在通道坐标系计算；滑移在真实接触表面切平面计算。

0.25 m/s、位置和角度容差、0.15 m/s 滑移尺度均是学习尺度初值，不是比赛容差或安全阈值。`P_ref`、`a_rate_ref`、允许高度范围和载荷软阈值取自合法运动、成功轨迹和硬件标定；未取得有效参数的对应代价保持零权重，不能虚构电机连续能力或落地允许力。

### 临边、姿态和载荷的计算细节

足端临边软余量初值可取 50 mm：`p_edge = mean_valid_contacts(clip(((m-d)_+/m)^2,0,1))`，无支撑时为 0。`d` 是足端实际支撑接触区域到边缘的有符号余量，不能仅按足中心或机身中心计算。落在通道外仍立即触发独立失败。

坡面参考从地形和当前支撑状态建立，坡脚、坡顶及多级支撑过渡要连续处理。直坡不要求机身强制贴成精确坡角，而是允许围绕可行参考姿态的范围。Elevation 可用滚转容差 5°、俯仰容差 10°作仿真起点，超差尺度分别用 15°、20°；容差相对参考面，不是相对世界水平。

楼梯支撑跨多个高度时，不能因机身正下方射线跳到新踏面就瞬间惩罚高度或俯仰。支撑参考不可靠时暂停相关软项并记录无效率，保留独立碰撞、关节与失控检测。Jump 参考取经能力练习验证的阶段姿态范围，不能直接套用楼梯姿态范围，也不能从未输入的墙高臆造 Actor 必须跟踪的不同轨迹。

载荷只惩罚超过阶段软阈值的部分：`p_impact = mean_i clip(((F_i-F_soft_phase)_+/F_scale_phase)^2,0,1)`。取物理子步或接触历史峰值；正常承重不扣本项，腾空没有接触则为零。现有代码的 100 N 示例阈值不能直接当作本机器人安全允许载荷。

法向速度项只在平地、连续坡面内部等参考可靠的阶段启用，不惩罚楼梯必要的上抬、下落以及 Jump 正常离地。没有可靠参考时，删除旧 `lin_vel_z` 比用错误参考惩罚更合适。

## 楼梯任务：逐级踏踩，完整通过才拿大额奖励

阶段为 `接近 → 逐阶通过 → 全身离开 → 出口恢复 → 完成`。上楼梯从底部出生，下楼梯从顶部出生，均朝通道正方向前进。

| 事件 | 实际一次奖励 | 必须满足 |
|---|---:|---|
| 某规定踏面首次覆盖 | +0.25 | 足底与该顶面真实有效接触，并且在合法支撑区域；六阶总额最多 +1.5 |
| 重复踩同一踏面、擦立面、悬脚靠近 | 0 | 不生成首次覆盖事件 |
| 全部踏面覆盖、全身离开且出口稳定 | +20 | 无失败、合法进入并通过完整障碍，初版稳定验证 0.5 s |
| 漏踩后抵达出口 | -50 并结束 | 明确记为覆盖失败，不能仅按位置给成功 |
| 掉到两侧、摔倒、严重越限等 | -50 并结束 | 同一步正事件全部屏蔽 |

顶面归属用接触位置、法向及对象判断；不凭足端 z 值接近台阶就给奖。六个规定踏面读取地图生成时保存的实际区域；末阶与平台连接时按连续支撑面处理。下楼梯记录每次下降后的实际落足面，出生平台不能自动填满覆盖位，最终地面仍需实际接触。必须全部六阶覆盖并完整离开第二段，不能在第一段或中间平台结束。

允许正常换脚和短暂腾空，不固定腿序、对角步态或每级哪只脚踩踏。既有的“至少两足接地才给摆腿时间奖励”、固定前伸限制、短支撑和左右支撑平衡等项初版不叠加；先确保它们不会抑制抬腿和跨级支撑，再按失败轨迹决定是否需要引入。

## 斜坡任务：相对坡面稳定，避免滑落和冲下坡

阶段为 `入口平台 → 坡面通过 → 出口平台 → 恢复 → 完成`。上、下坡分别训练。

- 主要正信号为有符号路径塑形和一次 +20 完成奖励，不因站在坡上直立持续给正奖励。
- 前向速度误差同时惩罚停滞、反向和超速，下坡不因惯性加速获得更高速度奖励。
- 滑移按坡面切向速度计算，沿坡正常运动不等于足底支撑滑动。
- 姿态和离地高度相对有效支撑面，坡度 20°本身不受“俯仰超过 5°”惩罚。
- 记录坡面真实支撑和上、中、下区域覆盖，验证确实通过坡面；若增加分段接触验收，应明确它是步行技能约束，不宣称为官方逐段踩踏条款。
- 出口恢复稳定 0.5 s 后发完成事件；滑下侧边或不能恢复均不能只凭越过终点算成功。

## 高墙 Jump：一次起跳、越墙、落地缓冲

阶段为 `准备/蹬地 → 腾空 → 落地缓冲 → 接管就绪`。阶段记忆在环境和外部调度器中维护，不增加 Actor 维度。

| 事件 | 实际一次奖励 | 必须满足 |
|---|---:|---|
| 首次有效起跳 | +0.5 | 位于已标定入口区，真实全足离地且运动方向有效，不是仅抬起一只脚 |
| 首次完整越墙 | +0.5 | 全身及各足从墙顶通过，无侧绕或借墙承重攀爬，不能仅检查机身中心 |
| 首次合法落地 | +0.5 | 有此前腾空历史，在墙后合法落地区产生真实支撑，不踩墙顶或侧边地面 |
| 落地缓冲后可由行走策略接管 | +20 | 已合法越墙、未失败、速度姿态及支撑状态满足验证过的接管条件 |
| 严重撞墙、借墙承重、侧绕、摔倒、越界等 | -50 并结束 | 失败优先，屏蔽同一步新的正事件 |

每个事件仅发一次；本回合即使反复蹲起、碰撞或再次离地也不重新发放。轻微擦碰作为负反馈处理，是否达到借墙承重或严重撞击按接触对象及标定阈值独立判定；不能把“比赛允许攀爬”误读为本次 Jump 任务也把攀爬算成功。

准备和腾空期间关闭正常行走的恒速误差、支撑不足、正向足摆幅限制、固定膝伸角和固定机身高度奖励。保留软关节限位、实际力矩限幅及失控检测；不能为允许蹬地伸腿而删除硬限位。

初版不使用未经验证的弹道落点预测或固定起跳垂直速度公式。用真实起跳区、实际净空、完整越墙和落地反馈引导探索；能力测试得到可靠目标后再加入弱起跳质量项，且不得持续奖励额外跳高或延长腾空。

单跳训练完成与整条链路成功分别统计。切回行走策略后再连续验证约 0.5 s 的恢复，刚接地即摔倒不能算闭环成功。不要强迫单帧 Jump 模型在落地后长期站稳，它没有独立的“已执行一次”观测；达到接管条件后由调度器退出，避免再次起跳。

## 失败、终止与禁止刷分的约束

以下是独立任务失败条件，不仅是软扣分：

- 任一足端在 800 mm 通道外有效支撑。悬空足的横向位置单独越界不等于支撑失败。
- 摔倒、机身异常撞地、严重失控或关节硬限制触发。
- 楼梯漏踩后越过最后补踩机会，或者错误入口、侧绕等非法路线。
- Jump 没有完成规定跳跃而以借墙、绕墙或落在错误区域代替。
- 任务期限已到但未完整完成；记为任务失败而非“到点自动成功”。

数值异常另记 `invalid_simulation`，不计为通过或可升级样本，并排查物理场景；不要只将 NaN 奖励替换为零后继续积累完成信号。严重真实失败不因奖励封顶变成可接受动作。

PPO 固定长度采样结束不代表任务失败；人为中断、外部评估采样截止等与任务结局无关的截断，需要保留相应 bootstrap 处理。成功、任务失败、外部截断和数值无效样本分别输出原因。

不启用总奖励最小值零裁剪，不丢弃负进度，不对“地形等级更高”单独加分，不把起跳次数、抬腿次数或接触次数直接当作长期正奖励。

### 首轮权重的量级核对

所有单项代价在 [0,1]，本表初始及计划启用的连续系数总和低于每秒 10，阶段开关不会放大到 1 以上。开发时对配置计算并记录这个上界，新增代价后重新核对。

在 dt=0.02、gamma=0.995 下，每秒 10 的最坏连续负代价的无限期折扣量级为 `0.02×10/(1-0.995)=40`。一次失败 50 大于这个初始连续代价预算；子事件累计最多 1.5，完整完成为 20，可先排除部分“主动提前摔倒以逃避负奖励”问题。

该量级检查不是所有策略排序或实机能力的保证。必须用停滞、往返、主动失败和正常通过轨迹比较实际折扣回报；势函数边界、超时语义或增加权重发生变化时，重新检查。不要把 -50 当成无需再检验的固定结论。

## 现有 Rough 奖励的继承与替换

| 现有项或做法 | 高程任务处理 |
|---|---|
| 三个速度 exp 正奖励 | 前向项改为负误差，避免长期存活累积正分；横向、航向按任务误差惩罚，避免重复加权 |
| `command_aligned_progress` | 替换为统一合法路线势函数，不再叠加旧进度奖励 |
| `command_progress_deficit` | 初版由速度误差、时间成本与任务完成约束覆盖，不再多项重复惩罚停滞 |
| 世界系 `lin_vel_z` | 移除直接惩罚；仅在参考可靠阶段考虑法向多余速度 |
| `pitch_excess` 的世界水平 5° | 替换为支撑面或阶段参考，允许正常坡角与起跳俯仰 |
| 每帧直立正奖励 | 改为超出可行姿态范围的代价，不奖励原地直立存活 |
| 支撑不足、长腾空、摆腿时间、固定膝伸角、固定足前伸限制 | 不直接叠加；Jump 起跳和腾空必须关闭不适用的行走项，硬关节限制保留 |
| `local_ground_clearance` 及高度终止 | 按支撑、跨台阶、腾空分别处理；参考未验证时软项先停用，不删严重异常保护 |
| `contact_forces` 的 100 N | 记录作诊断，重新标定阶段阈值后才用于归一化载荷代价 |
| 动作平滑、力矩、功率、关节限位 | 按本文归一化和阶段系数重建，不能将新系数直接套在旧原始量上 |
| `is_terminated` | 改为失败原因掩码的一次性事件；成功结束不受该惩罚 |
| 负奖励截零 | 不启用 |

## 课程与标定顺序

1. 验证几何、真实接触归属、通道边界、任务阶段、覆盖记忆和失败优先级。先用固定轨迹核对，再优化策略。
2. 从 Rough 权重迁移，先启用路径塑形、有限子事件、完整完成、失败、基本中线与姿态约束，以及已有硬限制。能耗和冲击等可选项先保持弱或关闭。
3. Elevation 从 40 mm 台阶、约 6.67° 坡起步。Jump 先进行单独的平地小跳和缓冲练习，再进入正式 110 mm 墙高；正式五档规格不因前置练习被改写。
4. 按任务允许类型分别统计完整通过，当前上限的最近 100 个有效已结束回合成功率达到 80% 后才释放下一档。楼梯或坡面的成功不能替 Jump 解锁墙高。
5. 采集成功、失败、原地不动和主动摔倒轨迹，对比分项累计、实际折扣回报和负载，再逐项启用滑移、动作变化、能耗和落地载荷细化。一次只调整一类主要因素。
6. 加入真实行走入口状态、触发误差、适度物理随机化及已开放难度复习，验证盲视模型在目标使用范围的覆盖。
7. 最后测试多策略切换和连续三墙，优化通行效率；不要只根据训练奖励挑模型。

## 必须记录与验证的结果

每回合记录地形与等级、阶段、前向和横向速度、中线与航向误差、足端临边余量、踏面覆盖、支撑滑移、接触对象、首次事件标记、最大负载、完成时间及失败原因。每项奖励记录原始值、归一化值、加权实际累计和折扣累计。

至少覆盖以下反例：

| 测试场景 | 应观察到的结果 |
|---|---|
| 原地直立、不前进 | 不因直立持续获正奖励，也不能获得完成事件 |
| 前进再退回同一位置 | 不靠舍弃负进度或重置阶段刷取路径奖励 |
| 重复踩同一级、擦台阶立面 | 不重复给覆盖奖励，不冒充顶面真实接触 |
| 漏踩台阶后到达出口 | 覆盖失败，完成奖励为零 |
| 正常 20° 上、下坡 | 坡角本身不触发世界水平姿态惩罚 |
| 正常起跳、全足离地 | 不被支撑不足或固定机身高度条件误终止 |
| 空跳、反复抬脚、跳得更高更久 | 有限事件去重，不获得持续跳高或腾空奖励 |
| 借墙攀爬、侧绕、落在墙顶 | 不能获得整机跳墙完成奖励 |
| 刚触地即摔倒 | 没有恢复完成，闭环不成功 |
| 主动摔倒提前结束 | 实际折扣回报不应优于可行的合法通行 |
| 同一步既到终点又越界 | 失败优先，新的正事件均为零 |
| 更换控制周期 | 连续积分及单次事件尺度正确，gamma 同步换算 |
| 切换模型、重复 ROS 触发 | 动作历史连续；跳跃期间重复请求不重置技能 |

分别报告 Elevation 四类地形五档、Jump 五档及 330 mm 目标墙的 nominal / robust 成功率。首轮验收目标沿用 90% / 80%，每用例五组固定种子合计 100 回合；这些是待验证目标。连续三墙单独报告整条路线通过率和切换后恢复，不能以单墙平均通过率代替。
