## 关节与模型

当前机器人为四腿、每腿三个主动关节，共 12 个动作，没有驱动轮动作。

策略顺序固定为腿优先：`fl`、`fr`、`rl`、`rr`；每腿内部依次为 `hip_abduction_joint`、`hip_pitch_joint`、`knee_joint`。例如前三个动作对应 `fl_hip_abduction_joint`、`fl_hip_pitch_joint`、`fl_knee_joint`。

| 名称 | 当前值 |
|---|---|
| 默认模型 | `mjcf/pointleg.xml` |
| 外部模型变量 | `POINTLEG_XML`，在启动进程前设置 |
| 基座 body | `base_link` |
| 足部 body | `{fl,fr,rl,rr}_foot_Link` |
| 足端 site | `{fl,fr,rl,rr}_foot_site` |
| 软关节限位系数 | 0.95 |

MJLab 保留 XML 的自然关节顺序，动作类会检查实体和动作目标都严格符合 `LEG_JOINT_NAMES`。不能只改关节名正则而忽略模型顺序。`get_spec()` 会移除 XML 自带执行器和关键帧，由训练配置重建执行器与初始姿态，并统一十二个关节的总力矩限幅。

## 姿态和执行器

| 参数 | 当前值 |
|---|---|
| 站立基座高度 | 0.42 m |
| 站立默认角 | 外展 0、髋俯仰 0.550、膝 -1.125 rad |
| Crawl 基座高度 | 0.20 m |
| Crawl 默认角 | 左外展 +0.4、右外展 -0.4、髋俯仰 1.65、膝 -2.50 rad |
| 控制方式 | `BuiltinPositionActuatorCfg`，位置 PD |
| Kp / Kd | 50.0 / 1.5 |
| 仿真力矩上限 | ±25 N·m |
| 物理步长 / 控制降采样 | 0.005 s / 4 |
| 控制周期 | 0.02 s，50 Hz |

动作链：原始网络输出 → 回合内固定的延迟缓冲 → 5 Hz 一阶低通 → 按关节缩放 → 加默认关节角 → 裁剪到软限位 → PD 执行器。

髋外展缩放为 0.125 rad，其余关节为 0.25 rad。高斯策略输出没有固定 ±1 边界，缩放值不是最终允许偏转上限。低通系数为 `1-exp(-2*pi*5/50)`；训练延迟在 0～2 个控制步之间按环境重置采样。回合重置需清除原始动作、滤波与延迟历史。

## 基础观测约定

除梅花桩外，当前任务 Actor 使用单帧 45 维，没有叠加历史帧。

| 顺序 | 内容 | 维度 | scale |
|---|---|---:|---:|
| 1 | 机身角速度 | 3 | 0.25 |
| 2 | 机身坐标系重力投影 | 3 | 1 |
| 3 | `twist` 速度命令 | 3 | 1 |
| 4 | 相对默认姿态的关节位置 | 12 | 1 |
| 5 | 相对默认值的关节速度 | 12 | 0.05 |
| 6 | 上一次原始策略动作 | 12 | 1 |

Critic 为基础 45 维加机身线速度 3、足端接触 4、高度扫描 273，共 325 维；线速度 scale 为 2.0。Actor 训练带噪声，Critic 不带观测噪声；网络配置关闭在线观测归一化。

RoughMixed的受阻射线、接触反馈和摆腿峰值统计没有加入Actor，不能把训练时的特权反馈解释为策略已直接看到障碍高度。2026-10-26新增的峰值指标及Elevation四髋持续偏置奖励都不改变45/325/12接口，也没有更改默认姿态、PD、力矩或关节硬限位。用户要求角度沟通使用度；代码内部仍可使用常规角度单位。

传感器 `history_length` 与策略历史观测不是同一概念。`rsl_rl/` 中保留 HIM 相关组件，但当前 `TASK_SPECS` 没有选择 HIM runner，不能套用历史 HIM 的输入维度或导出流程。

## 电机建模边界

十二个电机为 N6014B-12.6，供电记录为 48 V。参数位于 `motor_spec.py`：驱动峰值 31.7 N·m、制动峰值 34.4 N·m、60 V 空载转速 54.2 rad/s、减速比 `38/3`。

按电压比例得到的 48 V 空载转速约 43.36 rad/s，仅供核对，没有作为带载限速生效。参数已定义在减速器输出端，不再乘减速比。连续扭矩未知；当前没有电压、热、反电动势及完整扭矩—转速包络模型。±25 N·m 是仿真限幅，不能解释为硬件持续能力。详见 [电机参数](../docs/MOTOR_PARAMETERS.md)。
